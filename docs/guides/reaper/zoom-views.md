# Zoom & views

Shaping a session means constantly changing what's on screen — the mixer in, the FX browser out, zoomed to a bar or to the whole song. FastTrackStudio keeps the window toggles on mnemonic keys and folds zoom onto the mouse wheel so it stays under your pointer.

## Window toggles

- `kbd:@40078` — Toggle the mixer.
- `kbd:@40271` — Show the FX browser.
- `kbd:@40906` — Show the track manager.
- `kbd:@50124` — Show / hide the media explorer.

## Window sets

Save a whole screen layout and recall it instantly:

- `kbd:@40454` — Load window set 1.
- `kbd:@40455` — Load window set 2.

## Zoom on the wheel

Zoom lives on the mouse wheel with modifiers, so it happens wherever your pointer is:

- **Option + wheel** — zoom vertically (track height, or note height in the MIDI editor).
- **Shift + Option + wheel** — zoom horizontally (time).
- **Ctrl + Option + wheel** — zoom both axes together.

Same scheme in the arrange view and the MIDI editor. When the layout is right, bring up the mixer and read [[mixing|Mixing]].
