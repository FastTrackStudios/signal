# Mixing

Mixing is its own phase of the work, so it gets its own [[modes|mode]]. Activating Mix mode re-layers the keyboard around the mixer and level work, then steps aside when you leave it.

- `kbd:@_FTS_SESSION_MODE_MIX` — Enter Mix mode.
- `kbd:@40078` — Toggle the mixer (works in any mode).

```gif
mixing-mode
Entering Mix mode swaps the overlay to mixing bindings and brings the console forward.
```

## The idea

The base profile stays underneath — transport, navigation, and view toggles all keep working. Mix mode adds the level-, pan-, and send-oriented bindings on top, and can flip REAPER options that only make sense while mixing. Because it's a mode, nothing you learn here fights your editing muscle memory: the mixing bindings simply aren't live until you ask for them.

For the full picture of how modes layer and switch, read [[modes|Modes]]. The window and wheel controls you'll lean on while mixing are in [[zoom-views|Zoom & views]].
