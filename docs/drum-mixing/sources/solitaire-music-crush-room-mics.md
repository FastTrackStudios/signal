# Solitaire Music — crushing room mics

**A weak source** (generic, few numbers, partly scripted-sounding). Kept for
one point: it **disagrees with the fast/fast "1176 crush"** on attack.

- Stock compressor on the room: **"a relatively long attack time and a
  shorter release time"**, so the room "breathe[s] with the track"; then
  **ratio 10:1 or higher** "to emphasize the room ambience". Push further
  with more input gain and ratio (01:31–03:18).
- Listen to the compressed room with the rest of the drums, not soloed.

## Signal mapping (inference)

- Slow attack / fast release = the **groove** style (Tone) in
  `references/compression.md`; the 1176 crush (fast/fast) = **thickness**.
  Ours is 4:1, 3/120 ms (thickness-ish). The slow-attack version keeps room
  transients, which suits a mono "punch" room more than a wash.
