The sampler CLAP plays its track's timeline from a host's host-timeline/1 (Studio): it reads it on activation and on each timeline event, annotates off the audio thread, claims the track's playback so what still arrives is live input played beside the document, and reports no latency; elsewhere it reads the part from a .mid or JSON file ($SIGNAL_SAMPLER_CLAP_DOC). $SIGNAL_SAMPLER_CLAP_REFERENCE writes each schedule's reference render and arrivals for end-to-end tests (signal)
